# PACKSHIFT — Depth Trailer

## Goal

The video must explain the **idea underneath the interaction**, not list features.

Core statement:

> Packaging looks like graphic design, but it is a spatial negotiation with physical consequences.

Narrative arc:

`LIMIT → PRESSURE → CONSEQUENCE → COMPILATION → MEMORY`

Target length: **30–40 seconds**.

Primary format: **16:9** for portfolio / X / Contra.
Secondary cut: **9:16** from the same beats after the master edit is locked.

## Voiceover — master

> Packaging looks like graphic design. It isn't. Every claim, warning, language and code consumes physical space. PACKSHIFT makes that negotiation tangible. Start with the real front: fifty-six millimeters. Add requirements and the surface fills, rejects, even cracks under pressure. Behind the game, a spatial compiler opens the same package, redistributes information, and refolds it. The result is the same box, with a history, displayed as an artifact. Packaging is a compiled surface.

## Sound direction

Do not use generic cinematic risers throughout.

Sound hierarchy:

1. dry paper / print texture at the real-size opening;
2. placement ticks rise in pitch with surface pressure;
3. one hard low-frequency impact for overload;
4. hydraulic / metal pressure for level 5;
5. crease sequence during decomposition;
6. quiet room tone when entering the museum;
7. final acquisition-dot click.

The museum should be **quieter** than the rest of the video.

## Capture requirements for final master

Capture these clean shots after V7.1 is deployed:

- Taille réelle before fill;
- Taille réelle after mandatory-copy overflow;
- level 1 first successful placement;
- one over-capacity rejection;
- level 5 hydraulic press with visible shrink and CRAC;
- pro mode overloaded front;
- pro mode dieline / redistribution;
- museum with journey marks and provenance line.

No browser chrome for the final master.

## What the video must NOT become

- a feature carousel;
- a fast UI montage with no causal thread;
- a Blender showreel detached from the product;
- a compliance claim;
- a generic “AI solved packaging” story.

The product idea must remain legible without narration:

**the surface is finite, requirements compete for it, the object responds, and the result remembers what happened.**
